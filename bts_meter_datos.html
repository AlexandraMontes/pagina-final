Unidad 1 - Práctica 1: Registro de Personajes BTS

Ingresa los datos de un personaje de BTS. Los datos se guardan en el almacenamiento local del navegador (equivalente a un INSERT INTO en SQL) y pueden consultarse en "Mostrar Datos".

📘 Equivalencia SQL → localStorage:
INSERT INTO bts (nombre_real, personaje, Altura, ...) VALUES (?, ?, ?, ...)
→ JavaScript guarda el objeto en localStorage.setItem("bts-personajes", JSON.stringify(datos))
